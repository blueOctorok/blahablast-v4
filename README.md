# blahablast v4

Sam Blaha's portfolio. One page, built with Next.js 16 (App Router), TypeScript and Tailwind CSS v4.

```bash
npm install
npm run dev
```

The page's wording and links are in `src/content/`. What has changed and what is next are in `docs/CHANGES.md` and `docs/PROJECT_ROADMAP.md`.

Version 3 (Vite and React) is at [blueOctorok/blahablast-v3](https://github.com/blueOctorok/blahablast-v3).
